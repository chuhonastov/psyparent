# Кора

«Кора» — понятный справочник по детской психиатрии и дневник для родителей. Помогает разобраться в диагнозе и назначениях, вести записи о ребёнке между приёмами и прийти к врачу с понятной сводкой.

Автор — **Степан Краснощеков**, детский психиатр. Тексты написаны по двум его книгам — для родителей и для врачей; источники в карточках — клинические рекомендации, документы профессиональных обществ и исследования.

- Приложение: https://psyparent.vercel.app/ · в Telegram: [@psyparent_bot](https://t.me/psyparent_bot)
- Политика конфиденциальности: https://psyparent.vercel.app/privacy
- Канал автора: [@doc_kras](https://t.me/doc_kras)

Раньше приложение называлось PsyParent. Технические имена — ключи хранения `psyparent.*` и имя репозитория — остались прежними, чтобы у пользователей сохранились записи.

## Что умеет

**Справочник.** 69 тем в 12 разделах, 170 карточек препаратов и памяток, 421 написанный разбор «диагноз × препарат» (для остальных пар — общий разбор), 46 обследований, 11 специалистов и 69 планов немедикаментозной помощи, «Что не помогает» (31 метод), навигатор по России (ПМПК, школа, инвалидность, экзамены, бесплатная помощь), словарь. Поиск понимает сокращения, торговые названия и обычные вопросы родителей («не спит», «бьёт себя», «как пройти ПМПК»).

**Ребёнок.** Профиль (условное имя и месяц рождения), диагнозы из заключения, «Мои специалисты», цели. Лента лечения: препарат, доза из назначения, побочные эффекты, приёмы, документы. Короткий опрос раз в неделю или перед приёмом — цели семьи и то, что отслеживают при текущем препарате; тревожные признаки сразу показывают, что звонить врачу. «Сегодня» — одно главное дело и несколько необязательных.

**Помощь дома.** Мини-планы на две недели (утро, засыпание, уроки, вспышки, лесенка страха, экраны), паспорт для школы, план безопасности для подростка, поддержка для самого родителя, напоминания в календаре телефона.

**К врачу.** Памятка: вопросы, назначения, наблюдения, результаты тестов. PDF для специалиста — «Всё о ребёнке», памятка, «Что изменилось», лента: ключевые факты, тревожные признаки, «было → стало», цветная сетка опросов, таблицы лечения и тестов.

**Тесты и дневники.** PSC-17, SCARED, Vanderbilt, SNAP-IV, PHQ-9, GAD-7 прямо в приложении; M-CHAT-R/F, SDQ, CRAFFT 2.1 — по официальной форме с записью результата; YGTSS-R — со специалистом. 13 дневников наблюдений. Формы для учителя по ссылке: учитель отвечает без регистрации, ответ возвращается родителю ссылкой.

## Где хранятся записи

Подробно для пользователей — на странице «Политика конфиденциальности» (`webapp/src/pages/Privacy.tsx`). Её нужно менять вместе с любым изменением того, куда уходят данные.

- Записи — в localStorage браузера или окна Telegram; фото и PDF документов — в IndexedDB `kora-files`. Автору и на сервер приложения записи не передаются; регистрации, рекламы, статистики и cookie нет.
- В Telegram записи копируются в память Telegram на устройстве (DeviceStorage) и — только если родитель включит синхронизацию — в облако Telegram его аккаунта (CloudStorage). Копия — все ключи `psyparent.*` и `parentguide.*`, сжатые gzip, частями в две ячейки `kora_a*`/`kora_b*` с манифестом `kora_m`; в `kora.sync.v1` — хэши и время изменения каждого ключа, отметки удаления; побеждает более позднее изменение. Выключение синхронизации и «Удалить все мои записи» удаляют копию из облака.
- Только на устройстве, вне копий и синхронизации: черновики `kora.draft.*` (14 дней, по ребёнку, удаляются после сохранения), отложенные дела «Сегодня» `kora.snooze.v1` (`<childId>:<id>`; подтверждение тревожного признака — для одного опроса), напоминание о резервной копии `kora.backup.v1`, `kora.backupHint.v1`.
- Основные ключи: `psyparent.children.v1`, `psyparent.activeChild.v1`, `psyparent.profiles.v1` (диагнозы, специалисты, цели, что отслеживаем, `doctors`, `checkinEvery`, запуски мини-планов `plans`), `psyparent.treatment.v1` (лента лечения), `psyparent.checkins.v1` (короткие опросы; ответ родителя о себе `parent` в отчёты не входит), `psyparent.screenings.v1`, `psyparent.journals.v1`, `psyparent.visit.v2:<childId>` и `psyparent.appointment.v1:<childId>` (памятка и дата приёма по ребёнку), `psyparent.safety.v1`, `psyparent.passport.v1`, `psyparent.documents.v1`, `psyparent.requests.v1`, `psyparent.observations.v1:<id>`, `psyparent.recent.v1`, `psyparent.settings.v1`. Тесты и дневники связаны с ребёнком полем `childId` (старые — по имени).
- Удаление профиля удаляет его ленту, опросы, цели и планы, план безопасности, паспорт, документы и памятку; тесты и дневники остаются.
- Резервная копия — JSON `{app: "Kora", format: 1, data}` со всеми ключами `psyparent.*` и `parentguide.*`; полная копия добавляет `files` (изображения и PDF в base64, до 300 МБ). При восстановлении принимаются только эти ключи и типы файлов; итог показывается отдельно по записям и файлам.
- Вне Telegram главная напоминает о резервной копии, если её не делали 30 дней; на iPhone объясняется, что Safari может стереть данные сайта.

**Файлы и ссылки без сервера.**
- PDF, резервная копия и файлы календаря создаются на устройстве (`lib/files.ts`, `lib/pdf/*`, загружается по требованию). Telegram не даёт мини-приложениям сохранять файлы, поэтому там открывается браузер телефона по ссылке `/save#<данные>`: часть после «#» браузер на сервер не отправляет, страница делает файл на месте и убирает данные из адреса. Шрифт PDF — подмножество Liberation Sans под именем «Kora PDF Sans» (SIL OFL 1.1, `tools/build_pdf_font.py`).
- Формы для учителя (`lib/handoff.ts`): ссылка `/t#<код>`, ответ — `/import#<код>` или `t.me/psyparent_bot?startapp=<код>`. Код — JSON (при выгоде — gzip) в base64url, проверяется при открытии. Страница учителя ничего не сохраняет.
- Напоминания (`lib/reminders.ts`) — файл календаря с повтором; ссылка из события: `startapp=checkin_<childId>` или `startapp=plan_<id>` в Telegram, `/child/check-in?child=<childId>` или `/plans/<id>` в браузере.

## Telegram

- **Main Mini App** (обязательно): @BotFather → `/mybots` → @psyparent_bot → **Bot Settings** → **Configure Mini App** → **Enable Mini App** → `https://psyparent.vercel.app/`. Без него ссылки `t.me/psyparent_bot?startapp=…` (ответ учителя, напоминания) открывают только чат с ботом. Кнопка меню — `/setmenubutton`.
- **Политика конфиденциальности**: в настройках бота в @BotFather укажите ссылку `https://psyparent.vercel.app/privacy` — Telegram показывает её в меню мини-приложения.
- **Ответы бота** на `/start`, `/help`, `/app` даёт функция Vercel `webapp/api/telegram.ts`: ответ уходит прямо в ответе на вебхук, токен в Vercel не нужен, сообщения не сохраняются, в группах бот молчит. Один раз включить вебхук (подставьте токен из @BotFather, ссылку никому не пересылайте): `https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=https://psyparent.vercel.app/api/telegram`; проверка — `getWebhookInfo`. Необязательно: `TELEGRAM_WEBHOOK_SECRET` в Vercel и `&secret_token=…` в адресе; `WEBAPP_URL` меняет адрес кнопки «Открыть „Кору“».
- **«Написать автору»** открывает сообщения канала `https://t.me/doc_kras?direct` (`authorChannel` в `webapp/src/content/meta.json`). В канале должны быть включены личные сообщения: канал → «Изменить» → «Сообщения» → включить, бесплатно.
- **Число пользователей** в месяц показывает профиль бота в Telegram; своей статистики у «Коры» нет.
- **Иконки**: `branding/` (`python3 tools/build_icons.py`). `kora-avatar-640.png` — фото бота (`/setuserpic`), `kora-cover-640x360.png` — обложка мини-приложения (`/myapps`); имя и описание — `/setname`, `/setdescription`, `/setabouttext`.

## Разработка

Нужны Node.js 22+ и npm; зависимости зафиксированы в `webapp/package-lock.json`.

```bash
cd webapp
npm ci
npm run dev            # локальный запуск
npm test               # модульные проверки
npm run check:content  # структура и ссылки контента
npm run build          # сборка в webapp/dist
```

Самостоятельная HTML-копия для просмотра без установки — из корня проекта: `python3 tools/build_preview.py` (отдельная однофайловая сборка → `Kora-preview.html`, открывается в браузере, работает без сети).

Размещение: Vercel-проект с корневой директорией `webapp`, командой `npm run build` и папкой `dist`; `webapp/vercel.json` направляет внутренние адреса в `index.html`. Домен менять нельзя без переноса записей: локальные данные привязаны к адресу.

| Путь | Что там |
| --- | --- |
| `webapp/src/content` | Тексты: диагнозы, препараты, разборы, специалисты, навигатор, мониторинг, обычные вопросы, мини-планы, паспорт |
| `webapp/src/lib` | Логика: хранение и синхронизация, маршрут ребёнка, отчёты и PDF, формы для учителя, напоминания |
| `webapp/src/pages`, `components` | Экраны |
| `webapp/api/telegram.ts` | Ответы бота |
| `webapp/tests` | Модульные проверки |
| `docs/` | Рабочие документы: каталог, клиническая вычитка, дизайн, скрининги, дневники, проверки, пилот, план |
| `CHANGELOG.md` | История изменений |
