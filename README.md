# Кора · 0.22.0

Раньше приложение называлось PsyParent (рабочее название). Технические имена — ключи хранения `psyparent.*`, имя репозитория — остались прежними, чтобы у пользователей сохранились записи.

Приложение для родителей после консультации детского психиатра. Помогает понять уже поставленный диагноз, разобраться в цели назначения и собрать памятку для следующего приёма.

Автор проекта — **Степан Краснощеков**, детский психиатр. С версии 0.10 тексты написаны по двум книгам автора — для родителей и для врачей. Источники в карточках — независимые рекомендации, документы профессиональных обществ и исследования.

## Посмотреть без установки

Скачайте `Kora-preview.html` и откройте его в обычном браузере. Это рабочая самостоятельная копия приложения: можно переходить между экранами, выбирать вопросы и скачивать памятку. На телефоне может понадобиться сначала сохранить файл, затем выбрать «Открыть в браузере»; просмотрщик вложений не всегда запускает приложения внутри HTML.

Интернет нужен только при переходе на внешние источники. Если браузер запрещает локальное сохранение, приложение покажет сообщение. Данные этой копии не синхронизируются с опубликованным приложением или другим устройством.

Для первого знакомства с новой версией: **Диагнозы → Настроение → Депрессия → Понять / Помощь / К врачу**, затем **Помощь → поиск «Минирин» → Десмопрессин**, затем **К врачу**. Название препарата здесь служит примером поиска уже сделанного назначения.

Новый пример: **Помощь → поиск «Глиатилин» → Холина альфосцерат → Речь и язык**. Разбор объясняет недостаточность данных для этой цели. Из карточки диагноза дополнительные связи открываются во вкладке «Помощь» → «Разборы других назначений».

Новые разделы: **Главная → Специалисты**, либо **Диагнозы → нужная тема → Помощь → Немедикаментозная помощь**. В карточках описаны конкретные задачи, методы и ограничения; из них можно перейти к специалисту и сохранить вопрос врачу.

В разделе **Тесты** 10 инструментов. Прямо в приложении проходятся PSC-17, SCARED (формы ребёнка и родителя), Vanderbilt (формы родителя и учителя), SNAP-IV, PHQ-9 и GAD-7; для M-CHAT-R/F, SDQ и CRAFFT 2.1 открывается официальная форма, а результат записывается здесь. YGTSS-R заполняется вместе со специалистом.

Новый раздел **Тесты → Дневники и формы** содержит 13 форм: сон, поведение, переносимость терапии, наблюдения педагога, цели помощи, жалобы, тревога, настроение, тики, ритуалы, питание, туалетные трудности и коммуникация. Можно сохранять, редактировать, продолжать наблюдения, фильтровать историю и выбрать записи для врача. Это формы наблюдений без диагностических баллов. Подробности — в `docs/JOURNALS.md`.

## Что нового в 0.18

- **Форма для учителя по ссылке.** Родитель отправляет учителю или воспитателю ссылку на Vanderbilt (форма учителя), SNAP-IV или «Наблюдения педагога». ## Что нового в 0.17

- **Личный маршрут ребёнка.** Нижнее меню: «Сегодня», «Ребёнок», «Справочник», «Тесты», «К врачу». Наверху главной не каталог, а дела на сегодня: «14-й день после увеличения дозы», короткий опрос, дневник, приём через 12 дней, тревожный ответ в опросе.

- **Лента лечения:** препарат → доза → самочувствие → побочные эффекты → шкалы → приёмы, по датам. Тесты и дневники ребёнка попадают в неё сами.

- **«Что изменилось с прошлого приёма»:** сводка за период — изменения доз, цели «было → стало», побочные эффекты, вес и пульс, шкалы, записи. Входит в памятку к приёму.

## Разработчику: локальный запуск

Нужны Node.js 22+ и npm. Проверено на Node.js 24.19.0. Установки зафиксированы в `webapp/package-lock.json`.

```bash
cd webapp
npm ci
npm run dev
```

Проверка и сборка:

```bash
npm test
npm run check:content
npm run build
```

Восстановить самостоятельный HTML после сборки:

```bash
python3 tools/build_preview.py
```

Эту команду выполняют из корня проекта. Для HTTP/HTTPS используется BrowserRouter, для самостоятельного HTML — HashRouter. Используется системный шрифт; внешние шрифты, аналитика и API для записей не подключены. Ссылка `t.me/psyparent_bot?startapp=` открывает основное мини-приложение бота — оно должно быть настроено в @BotFather (Main Mini App).

## Размещение приложения

Для Telegram нужен публичный HTTPS-адрес. Приложение можно разместить на существующем Vercel-проекте с корневой директорией `webapp`, командой сборки `npm run build` и выходной папкой `dist`. Конфигурация `webapp/vercel.json` направляет внутренние маршруты в `index.html`.

На другом статическом хостинге нужно такое же правило: существующие файлы отдавать как файлы, остальные адреса приложения направлять в `index.html`. После размещения проверьте прямое открытие и перезагрузку `/diagnoses/adhd` и `/visit`.

Для переноса уже существующих записей сохраните прежний домен: локальные данные привязаны к адресу и браузеру. При смене домена родителю понадобится заранее скачать памятку.

## Бот

Бот [@psyparent_bot](https://t.me/psyparent_bot) не требует своего сервера.

- **Основное мини-приложение (Main Mini App) нужно включить обязательно** — без него ссылки вида `t.me/psyparent_bot?startapp=…` (ответ учителя, ссылки для статистики) открывают только чат с ботом. В @BotFather: `/mybots` → @psyparent_bot → **Bot Settings** → **Configure Mini App** → **Enable Mini App** → отправьте адрес `https://psyparent.vercel.app/`. После этого в профиле бота появится кнопка «Открыть», а ссылки `?startapp=` будут открывать «Кору».
- Кнопка меню в чате задаётся отдельно: `/setmenubutton` (тот же адрес). Telegram хранит эти настройки у себя.
- Ответы на `/start`, `/help`, `/app` и обычные сообщения даёт функция Vercel `webapp/api/telegram.ts` — она собирается вместе с приложением и обновляется при каждом слиянии в `main`. Ответ уходит прямо в ответе на вебхук, поэтому токен бота в Vercel не нужен. Сообщения не сохраняются и не пишутся в журнал; в группах бот молчит.

Чтобы бот начал отвечать, один раз откройте в браузере адрес (подставьте токен из @BotFather, ссылку никому не пересылайте):

```
https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=https://psyparent.vercel.app/api/telegram
```

В ответ Telegram покажет `{"ok":true,...}`. Проверка: `https://api.telegram.org/bot<ТОКЕН>/getWebhookInfo`. Отключить — `deleteWebhook`.

Необязательно: чтобы функция принимала запросы только от Telegram, задайте в Vercel переменную `TELEGRAM_WEBHOOK_SECRET` (латиница, цифры, `_`, `-`) и добавьте к адресу выше `&secret_token=<то же значение>`. Переменная `WEBAPP_URL` меняет адрес кнопки «Открыть „Кору“»; по умолчанию используется домен, на который пришёл вебхук.

## Обратная связь и число пользователей

«Написать автору» открывает сообщения Telegram-канала [@doc_kras](https://t.me/doc_kras) по ссылке `https://t.me/doc_kras?direct`. Чтобы она работала, в канале должны быть включены личные сообщения: канал → «Изменить» → «Сообщения» (Direct Messages) → включить, цену оставить бесплатной. Если выключить, ссылка откроет сам канал. Адрес канала задан в `webapp/src/content/meta.json` (`authorChannel`).

Своей статистики у «Коры» нет. Число пользователей в месяц Telegram показывает сам — в профиле бота с включённым Main Mini App («… пользователей в месяц»); для этого приложению ничего не нужно передавать.

## Записи родителей

Записи хранятся в localStorage. Они не отправляются автору, врачу или на собственный сервер приложения. Экспорт текста, отправка и резервная копия выполняются только по нажатию пользователя.

В Telegram записи дополнительно копируются в хранилище Telegram (`sync.ts`):

- **Память Telegram на устройстве** (DeviceStorage, Bot API 9.0+) — всегда. Если окно мини-приложения потеряло localStorage, при следующем открытии записи возвращаются до первого экрана (ожидание не больше 1,5 с).
- **Облако Telegram** (CloudStorage, Bot API 6.9+) — только если родитель включил «Синхронизировать между устройствами» в разделе «О приложении». Синхронизация включена для аккаунта, пока в облаке есть копия; выключение и «Удалить все мои записи» удаляют копию из облака.

Копия — JSON всех ключей `psyparent.*` и `parentguide.*`, сжатый gzip и записанный в base64 частями (4000 символов для облака, 16 000 — для устройства) в одну из двух ячеек `kora_a*`/`kora_b*`; манифест `kora_m` переключается на новую ячейку только после записи всех частей и хранит хэш для проверки. Для каждого ключа в `kora.sync.v1` хранятся хэш значения и время изменения; при слиянии побеждает более позднее изменение, удаление оставляет отметку, поэтому удалённое не возвращается из старой копии. Записи, созданные до первой синхронизации, уступают уже синхронизированным, а списки с `id` (результаты тестов, дневники, дети) при первом объединении двух устройств складываются.

Вне Telegram на главной появляется напоминание о резервной копии, если есть записи, а копии не было 30 дней (можно отложить на 14 дней; `kora.backup.v1`, `kora.backupHint.v1`). На iPhone и iPad вне экрана «Домой» напоминание и раздел «О приложении» объясняют, что Safari может стереть данные сайта, который не открывали неделю. `manifest.webmanifest` позволяет добавить «Кору» на экран «Домой» как отдельное приложение; браузер просит не вытеснять данные (`navigator.storage.persist`, кроме Firefox).

Новая структура — `psyparent.visit.v2`. Чтение поддерживает старые ключи `parentguide.*`; после первого изменения используется версия 2. Старые данные не удаляются автоматически. «Очистить вопросы, назначения и наблюдения» оставляет отметки в карточках и историю скринингов; «Удалить все мои записи» в разделе «О проекте» удаляет все поколения записей приложения, включая историю и ответы скринингов.

Наблюдения всех диагнозов используют `psyparent.observations.v1:<id>`. Новые ответы имеют приоритет над старыми отметками. Общую справочную памятку нельзя добавить как отдельный препарат; записи, ранее внесённые пользователем, не удаляются при обновлении.

Дата приёма — `psyparent.appointment.v1`, недавно открытые карточки (до шести) — `psyparent.recent.v1`, размер текста и тема — `psyparent.settings.v1`. Эти ключи не меняют структуру памятки и удаляются вместе со всеми записями.

Маршрут ребёнка (0.17): `psyparent.profiles.v1` — по `childId` диагнозы, специалисты, цели (`severity` — «нет / немного / заметно / сильно», `count` — раз за неделю) и что отслеживаем (`items`, свои пункты `custom`, дневники `journals`, уже применённые наборы `sets`); `psyparent.activeChild.v1` — выбранный ребёнок; `psyparent.treatment.v1` — события ленты (`start`, `dose`, `stop`, `visit`, `effect`, `side`, `exam`, `event`; доза — текст из назначения, приложение её не проверяет); `psyparent.checkins.v1` — короткие опросы. «Сегодня» и «Что изменилось» вычисляются из этих записей, тестов и дневников (они связаны с ребёнком по имени) и ничего не хранят. Сводка «Что изменилось» считается от последнего отмеченного приёма (если он был не раньше полугода назад), иначе за 6 недель. При удалении профиля удаляются его лента, опросы и цели; тесты и дневники остаются.

Добавлено в 0.18: `psyparent.safety.v1` — план безопасности по `childId` (признаки, что помогает, контакты, безопасный дом, что важно); `psyparent.documents.v1` — список документов (тип, дата, название, главное из документа, сведения о файле), а сами файлы — в IndexedDB `kora-files` этого браузера: они не входят в синхронизацию, переносятся только полной резервной копией (с 0.19) и удаляются вместе с документом, профилем или «Удалить все мои записи»; `psyparent.requests.v1` — отправленные учителю формы и отметка об ответе.

Добавлено в 0.19: памятка и дата приёма хранятся по ребёнку — `psyparent.visit.v2:<childId>` и `psyparent.appointment.v1:<childId>` (ключи без суффикса — пока профилей нет; при появлении профилей их содержимое переходит первому ребёнку). Тесты и дневники получили поле `childId`; старые записи связываются с профилем по имени при запуске, при переименовании ребёнка подпись записей меняется вместе с ним. В профиле — `doctors` (до 5: имя, кто это, телефон, где принимает) и `checkinEvery` (7, 14 или 0 — только перед приёмом). Только на этом устройстве, вне копии и синхронизации: черновики `kora.draft.*` (14 дней, удаляются после сохранения) и отложенные дела «Сегодня» `kora.snooze.v1`. Полная резервная копия добавляет `files` — файлы документов в base64 (только изображения и PDF, до 300 МБ); обычная копия файлов не содержит.

Добавлено в 0.20: черновики форм привязаны к ребёнку (`kora.draft.checkin.<childId>`) и не пишутся после сохранения; формы ребёнка открываются заново при переключении, а введённое без черновика переспрашивает; отложенные дела «Сегодня» — `kora.snooze.v1` с ключами `<childId>:<id>`, предупреждение — `urgent-<id опроса>` (подтверждение действует только для этого опроса). Файлы скачиваются как PDF (`lib/pdf/makePdf.ts`, загружается по требованию; шрифт — подмножество Liberation Sans под именем «Kora PDF Sans», SIL OFL 1.1, пересборка `python3 tools/build_pdf_font.py`). В Telegram скачивание идёт через `/save#<данные>` во внешнем браузере (`lib/files.ts`): часть ссылки после «#» браузер не отправляет на сервер, страница делает файл на месте и убирает данные из адреса.

Добавлено в 0.21: `psyparent.passport.v1` — паспорт для школы по `childId` (как обращаться, шесть списков, «важно знать», до 3 контактов, `showDiagnosis` — по умолчанию нет); удаляется вместе с профилем. В профиле — `plans`: запуски мини-планов (`planId`, `goalId` — цель в опросе, `startedAt`, `until` — через 14 дней, отмеченные шаги `done`, `status`). Пока план идёт, короткий опрос предлагается раз в неделю. В коротком опросе — `parent` (0 справляюсь, 1 тяжеловато, 2 очень тяжело): не входит ни в памятку, ни в отчёты. Тексты планов и подсказки паспорта — `plans.json`, `passport.json`. PDF для специалиста строятся из блоков (`lib/pdf/doc.ts`, `lib/reports.ts`), остальные — из текста. `kora.stats.v1` версии 0.20 удаляется при запуске.

Добавлено в 0.22: напоминания — файл календаря (`lib/reminders.ts`, `components/Reminder.tsx`) с повтором `RRULE` и сигналом в выбранное время; приложение ничего не хранит. Ссылка из события: в Telegram `t.me/psyparent_bot?startapp=checkin_<childId>` или `startapp=plan_<id>` (нужен Main Mini App), в браузере `/child/check-in?child=<childId>` или `/plans/<id>`; остальные `startapp` — ответы учителя. Ответ «А как вы сами?» 1 или 2 даёт напоминание о странице поддержки на «Сегодня» в течение недели.

Формы для учителя (`handoff.ts`) работают без сервера. Ссылка `/t#<код>` содержит форму, имя ребёнка для учителя, возраст и сообщение родителя. Ответ — ссылка `/import#<код>` или, если запрос отправлен из Telegram и код короче 512 символов, `https://t.me/psyparent_bot?startapp=<код>`: мини-приложение получает его как `start_param` и открывает «Ответ учителя». Код — JSON (при выгоде — gzip) в base64url; при открытии он проверяется по форме (число и диапазон ответов, возраст), а ответ сохраняется как результат шкалы с отвечающим «Учитель» или запись «Наблюдения педагога». Страница учителя ничего не сохраняет в его браузере и не показывает меню приложения.

Резервная копия — JSON-файл `{app: "Kora", format: 1, data}` (копии с `app: "PsyParent"` из прежних версий тоже восстанавливаются) со всеми ключами `psyparent.*` и `parentguide.*` этого браузера. При восстановлении принимаются только такие ключи; текущие записи приложения заменяются, а при ошибке сохранения возвращаются. Каждая запись после восстановления проходит обычную проверку при чтении. Файл содержит ответы тестов и дневники: храните его как медицинский документ.

Скрининги хранятся отдельно в `psyparent.screenings.v1`. Каждое прохождение — отдельная запись. До явного сохранения ответы формы не сохраняются. Сохранённые записи доступны людям с доступом к браузеру; можно использовать условное обозначение ребёнка. Между устройствами история переносится резервной копией, а в Telegram — синхронизацией, если её включить. Внешний сайт опросника имеет собственные условия; «Кора» не передаёт ему ваши записи.
