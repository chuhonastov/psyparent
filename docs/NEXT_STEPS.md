# Следующие шаги после 0.9.0

Готовы 69 тем, 170 карточек лекарств / добавок / памяток, 395 разборов назначений, 11 специалистов, 69 планов немедикаментозной помощи (208 связей) и 10 инструментов скрининга и клинической оценки, а также 13 дневников и форм наблюдений. В 0.9.0 обновлено оформление и добавлены поиск по всему справочнику, дата приёма с календарём, отправка памятки, настройки чтения и резервная копия.

1. Авторский просмотр новых планов помощи и границ методов по `CLINICAL_REVIEW.md`. Проверить приоритетные ситуации, квалификацию специалистов и понятность целей для родителей.
2. Проверить формулировки и маршруты скринингов по `SCREENINGS.md` и `JOURNALS.md`. Для электронной репродукции внешних форм учесть актуальные условия их правообладателей; текущая версия уже позволяет открыть исходную форму и сохранить её результат. Новые инструменты добавлять с установленным источником перевода, возрастом, правами и тестами подсчёта.
3. Продолжить сверку конкретных российских инструкций лекарств, возрастных показаний, форм и доступности. Наличие карточки не подтверждает эффективность.
4. Разместить на прежнем HTTPS-домене, если требуется обновить опубликованное приложение. Публичное размещение этой версии не выполнялось. Прежний адрес важен для доступа к локальным записям.
5. Проверить Android и iPhone внутри Telegram: клавиатуру, внешние формы и возврат, сохранение тестов и дневников, редактирование, сравнение, выбор для памятки, копирование / скачивание, перезапуск и очистку. Отдельно для 0.9.0: кнопку «Отправить» (меню телефона или выбор чата Telegram), скачивание `.ics` и файла копии, выбор файла при восстановлении, окраску шапки Telegram, крупный текст. Некоторые версии Telegram не скачивают файлы из мини-приложений; тогда нужен запасной путь (копирование текста или отправка файла ботом). Эмуляция Chromium не заменяет проверку телефонов.
6. Провести закрытый пилот по `PILOT.md`, затем устранить ошибки и непонятные формулировки. Проверять, понимают ли люди разницу между скринингом и диагнозом, ограничением метода и бесполезностью профессии, сохранением истории и выбором результатов для врача.

## Что можно добавить дальше

Идеи, для которых нужно решение автора или клинический текст; в 0.9.0 они не реализованы.

- **Профиль ребёнка без персональных данных** (условное имя и возраст): тесты, дневники и возрастные подсказки сразу фильтруются по возрасту, а записи разных детей не смешиваются.
- **Графики в дневниках**: динамика числовых полей (сон, частота эпизодов, баллы шкал) между приёмами — удобнее таблицы для разговора с врачом.
- **Словарь терминов** с пояснением по нажатию прямо в тексте карточек (нужны авторские определения).
- **Напоминания через бота** о приёме или о записи в дневник. Требует хранения даты на сервере, поэтому только по явному согласию.
- **Работа без сети после первого открытия** (service worker) и разделение сборки: сейчас справочник загружается одним файлом ~1,4 МБ (≈330 КБ в gzip), разборы назначений можно подгружать по требованию.
- **Форма для педагога по ссылке**: учитель заполняет наблюдения в своём браузере и отправляет родителю текст, без серверного хранения.
